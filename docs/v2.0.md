## 2026-10-02 — Full Project Audit (Senior Review)

> **Goal:** End-to-end review of the project as an experienced tester/reviewer — assess what's solid, what's blocking launch, and what new features/components would best suit a B2B plastic spare parts manufacturer.
> **No code was changed in this pass.** This entry documents findings and the agreed feature roadmap.

### What's Solid (confirmed, no action needed)

- Content model (`/content/*.ts`) — all copy centralised, zero hardcoding in components
- Animation system — GSAP + Lenis properly wired, reduced-motion respected everywhere
- Form fallback chain — POST → WhatsApp → mailto; buyer can always reach Alok even if PHP endpoint dies
- Token-only CSS — no arbitrary values, all colours lint-gated
- SEO foundation — Organization + LocalBusiness JSON-LD in place, per-page title/description scoped

### Critical Blockers (launch-blocking, no code yet)

| Blocker | Where | Action needed |
|---|---|---|
| `site.contact` all null | `src/content/site.ts` | Client to provide phone, WhatsApp, email, mapsUrl, GSTIN, geo coords |
| `/api/enquiry.php` untested | `public/api/enquiry.php` | Verify end-to-end: PHP runtime + email delivery |
| No `og:image` | All pages | Add per-page Open Graph image — WhatsApp/LinkedIn previews are blank |
| No `sitemap.xml` | `public/` | Generate static sitemap at build time |

### Agreed Feature Roadmap (priority order)

| Priority | Feature | Why | Effort |
|---|---|---|---|
| 1 | **PDF Catalogue download** | B2B buyers forward PDFs to procurement committees; `trackCatalogueDownload()` already in analytics.ts | 1–2 days |
| 2 | **WhatsApp contextual button on product pages** | `waProduct()` in `src/lib/whatsapp.ts` already written — just needs wiring to a button | 1 hr |
| 3 | **Testimonials strip** (3–4 B2B buyer quotes) | Zero buyer voices on site currently; "70%+ repeat customers" is a stat — a human saying it is a signal | 1 day (copy-gathering) |
| 4 | **Material comparison table** | Engineers (OEM decision-makers) buy by material spec, not part name; no competitor has this | 4 hrs |
| 5 | **Print / spec sheet** (CSS `@media print`) | Procurement managers print and email spec sheets; existing `PartSheetArt` SVGs were built for this | 4 hrs |
| 6 | **Error Boundary + Toast system** | No error boundary = blank page on any component throw; toast = form feedback survives navigation | 3 hrs |

### Features Explicitly Rejected

Blog, live chat widget, product comparison table, customer portal/login, newsletter signup, PWA/service worker — all skipped because they don't match the business model or would create maintenance debt with no conversion payoff.

## 2026-10-02 — Human Feel & Copy Overhaul (Senior Dev Audit Pass)

> **Goal:** Make the site feel like a real Chandigarh manufacturer since 1998 — not a committee-approved B2B template.
> **Rule:** No invented facts. All `TODO(client)` items need client confirmation before going live.

### `src/content/site.ts`

| Field | v1 | v2.0 | Why |
|---|---|---|---|
| `hero.ctas.primary` | `Enquire Now` | `Send Your Requirement` | "Enquire Now" is corporate-generic. "Send Your Requirement" is how a B2B buyer actually talks — specific, actionable |

## 2026-10-02 — Career Page Layout Fix (Round 2)

> **Goal:** Put the four-teams panel in proper document flow (BREADCRUMB → LABEL → Heading → Lead → Teams sheet), so the large heading never overlaps the team grid and spacing is proportional at every viewport.
> **Root cause:** The team sheet was rendered inside `CareerArt` (absolutely positioned art layer), and `PageHero`'s stack h1 margin was only `--space-md` (24px) — far too tight for a 100px heading.

### `src/components/page/art/CareerArt.tsx`

| What | v1 (Round 1) | v2 (Round 2) | Why |
|---|---|---|---|
| Sheet markup | Rendered inside art with no CSS (invisible) | Removed entirely | Sheet moved to PageHero children for document flow |
| `careerConfig` import | Present | Removed | No longer needed after sheet removal |

### `src/app/career/page.tsx`

| What | Changed |
|---|---|
| New CSS block: `.cr-hero-sheet` + children | 8 rules: bordered mono panel, 2×2 cell grid, accent first cell, footer row with culture words |
| `<PageHero>` children | Added `<div className="cr-hero-sheet">` with 4 teams mapped from `careerConfig.teams` and footer "Joyful · Supportive · Trustworthy" |

### `src/components/page/PageHero.tsx`

| Rule | What changed | Why |
|---|---|---|
