## Stack facts — read before editing (do NOT ignore)
- Framework: Next.js (App Router). Components are TSX with **CSS-in-JS `<style>` blocks or imported
  `.css` files**. This project does **NOT** use Tailwind utilities in these sections — do not add
  Tailwind classes or arbitrary `[..]` values.
- Styling is **design-token driven**. `src/styles/tokens.css` is the **ONLY** file where raw hex may be
  defined. Every colour in components must be a CSS custom property (`var(--…)`) or a `color-mix()` of
  tokens.
- Lint enforces this:
  - `scripts/check-hex.mjs` — fails on ANY hex not in its `ALLOWED_HEX` set. If you introduce a new
    token hex, you MUST add it to BOTH `src/styles/tokens.css` AND `ALLOWED_HEX` in `check-hex.mjs`.
  - `scripts/check-spacing.mjs` — fails on spacing **28–36px** ("ambiguous zone"), including `2rem`
    (32px). Use the `--space-*` scale: xs 8, sm 16, md 24, lg 40, xl 72 (px).
  - Pure black `#000` / `#000000` is forbidden (§2.4); use `--ink` or a `color-mix` with
    `--burgundy-night` for shadows.
- Fonts available (self-hosted): `--font-archivo` (display/expanded), `--font-inter` (body,
  neo-grotesque), `--font-devanagari`, `--font-mono`. There is **no** Plus Jakarta / Poppins etc.
- Motion must be gated by `@media (prefers-reduced-motion: no-preference)`, with a finished static
  state under `reduce`.
- After EVERY task group: run `pnpm lint && pnpm typecheck`. Report a per-file diff.
