# 15. FLOW PRINCIPLES

Apply these rules.

## ONE IDEA = ONE SECTION

If two sections teach essentially the same concept:

* Merge them
* Relocate one
* Or remove one

---

## EARN THE NEXT SECTION

Every section should naturally create the question answered by the next section.

If:

Section A → random jump → Section B

then reconsider the order.

---

## FRONT-LOAD THE ANSWER

The primary user question should be answered:

* Above the fold
* Or within the first two sections

---

## TRUST BEFORE PITCH

Evidence
→ Explanation
→ Value
→ CTA

## ONE PRIMARY CTA

## DEPTH MUST BE EARNED

A short page that answers the user's question is better than a long page filled with repetition.

Cutting a section is a valid outcome.

# 37. CRITICAL HIGHLIGHT GOTCHAS

## GOTCHA 1 — GRADIENT TEXT

If a parent uses:

```css
-webkit-text-fill-color: transparent;
```

a nested highlight can become invisible.

Guard against this.

Either:

* Skip those subtrees
* Or explicitly restore text colour

Always visually verify.

---

## GOTCHA 2 — DEFAULT MARK YELLOW

Browser `<mark>` has a default yellow background.

Never allow that.

Explicitly define:

* Background
* Text colour

using only approved theme tokens.

---

## GOTCHA 3 — CLIPPED SECTIONS

The website uses:

* clip-path
* FoldEdge
* Notches
* Fold lines

The highlight must not:

* Overflow
* Cross a fold
* Break clipping
* Create visual artefacts

---

## GOTCHA 4 — MOBILE WRAPPING

Check at:

`375px`

Make sure highlighting does not cause:

* Awkward line breaks
* Horizontal scroll
* Broken headings
* Orphan words

---

## GOTCHA 5 — DEVANAGARI

The website uses Hindi / Sanskrit language contexts.

Do NOT force Latin keyword highlighting into Devanagari text.

---

## GOTCHA 6 — ACCESSIBILITY

Highlighting is decorative.

The content must remain fully understandable without it.

Do not use colour as the only semantic signal.

---

## GOTCHA 7 — MOTION

The highlight should be static.

No unnecessary animation.

Respect:

`prefers-reduced-motion`

and print.
